# 下一餐决策中的营养数据使用规则

营养查询与计算统一通过 Nutrition Tool，唯一内置营养数据集为 USDA FoodData Central。旧中文估算食品表和网页候选库已移除。模型不得凭记忆编造营养值，不得自行改写 USDA 原始数据。

## 查询路径

中文名称 → 固定中文别名/FDC 编号映射 → USDA 原始记录。
未收录的中文名称 → 模型仅转换英文检索词 → USDA 全文检索与相关性排序 → 自动匹配参考记录。
英文名称全文检索同样自动匹配，普通查询优先通用食品而非未指定品牌的配方，结果注明参考性质。精确 FDC 编号或原始完整名称可直接读取。

中文映射仅存名称、别名、类别与 FDC 编号，不另存营养值。Tool 返回中文名称、originalName、source、id 与每100g可食部的 per100g。

## 候选与匹配

- `usda_chinese_alias`：明确中文别名对应具体 USDA 条目；使用前核对显示的生熟状态和配方。
- `authoritative_database`：精确原名或 FDC 编号。
- `usda_generic_reference`：按相近 USDA 通用食品参考，须说明 matchNote；如鸡腿汉堡只匹配通用鸡肉汉堡时，不能声称 USDA 已验证具体鸡腿配方。
- `usda_search_reference`：中文翻译或英文全文检索后自动选择相关记录，confidence 为 medium，须保留参考提示。
- `source: unmatched`：当前快照没有可用结果；补充具体食品、生熟状态、配料或英文名，不退回旧估算库、网页估值或模型记忆。

“汉堡”直接使用通用汉堡记录；明确“牛肉汉堡”“芝士汉堡”“鸡腿汉堡”“炸鸡汉堡”时按品类匹配，不要求三选一。“芝士培根牛肉汉堡”必须检索完整菜品，不能只使用牛肉。

## 计算和来源

营养数值只从所选 USDA 条目读取，按实际克数确定性换算。保留原文、FDC 编号、来源链接、版本与每100g口径。缺失蛋白质等为未知，不能当作真实0。

常见食材的别名会明确展示对应状态，例如“鸡胸肉”对应“生鸡胸肉（去皮去骨）”；用户食用的是熟食时要改查“烤鸡胸肉”，不能直接混用。

DIY、菜单和图片分析没有匹配到的部分必须说明未能计算；匹配到通用参考时说明配方差异，不得以单一食材替代复杂菜品。份量是估计时仍要标注估算，权威的每100g数据不代表实际食用克数精确。

用户主动提供且对应当前商品的包装标签，仍可以作为用户输入手动记录，不写入 USDA 数据表。条码库和自动网页营养估值已停用。

账号、历史确认的饮食、体重与记忆记录不随食品库移除而删除，也不自动用新 USDA 数值改写历史摄入。
