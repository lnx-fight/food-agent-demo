# 下一餐决策中的营养数据使用规则

唯一内置营养数据集为台湾食药署（TFDA）的食品营养成分资料集，快照含2,213个食品和230,152条营养指标明细。USDA、旧中文估算表及网页候选库已移除。模型不得凭记忆编造或改写营养值。

## 查询

所有营养查询统一通过 Nutrition Tool：简繁体名称、已核对的俗名/别名、完整英文名或 `tfda:整合编号` → 对应完整样品 → 原始每100克可食部数据。简体名称由OpenCC转换，保留繁体原名、样品说明和来源。查询不依赖模型翻译或外部API，不将未收录的复合菜拆为某个食材。

- `tfda_exact_match`：精确食品名或整合编号。
- `tfda_name_alias`：明确名称别名，须核对返回的完整样品名、生熟状态及 matchNote。
- `tfda_sample_reference`：完整食品名的样品变体参考，置信度medium，须说明品种与样品限定。
- `source: unmatched`：当前快照没有可用完整记录，提示具体名称/TFDA编号或用户提供包装标签；不得改查USDA或用模型估值。

“米饭”对应官方“白飯”，“鸡胸肉”对应生的“去皮清肉平均值”。熟鸡胸不能套用生鸡胸。冷冻虾仁炒饭仅对应冷冻包装产品，不能用来代表任意现炒饭。当前快照没有“回锅肉”“牛肉汉堡”等条目时，应明确未匹配。官方“漢堡包”是面包，不能算作夹肉汉堡；“麻婆醬”也不能代表麻婆豆腐。不得隐藏冷冻、部位或做法词。

## 计算与来源

按用户确认的克数进行确定性换算。优先使用官方“修正熱量”kcal，缺失时用原“熱量”kcal；两种原始记录都保留，并显示所用口径。缺失营养素保持未知，不能当作零。无有效克重的每单位/每份值不得用于按份计算。不要将不同样品的热量和蛋白质拼成一条数据。

显示 source 中的提供机构、链接、整合编号、下载快照日期、署名和授权条款。数据依政府资料开放授权条款第1版使用。完整营养指标经 `/api/nutrition/details?q=tfda:编号` 读取。

图片、DIY、菜单与文字记餐共用同一匹配路径。未匹配的部分必须说明未计入；实际份量是估计时仍需注明估算。用户主动提供的当前商品包装标签可用于手动记录，不写入权威食品表。条码库与自动网页估值继续停用。

账号、已确认的历史饮食、体重、对话与记忆不随食品库替换删除，也不按新数据重算；旧USDA来源及编号作为历史记录保留，不再供新营养查询使用。
