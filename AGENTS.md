# Repository instructions

## Change log

For every user-requested change that materially edits code, configuration, documentation, or assets in this repository, update `CHANGELOG.md` in the same task.

- Use the current date in the Asia/Shanghai timezone.
- Append a concise Chinese entry under the latest date.
- State the requested outcome, the implemented result, and the main files changed.
- Mention important limitations, migrations, or incomplete work.
- Do not add a changelog entry for read-only inspection or explanation-only turns.
