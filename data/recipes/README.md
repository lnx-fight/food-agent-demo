来源：国家卫生健康委办公厅《成人肥胖食养指南（2024年版）》附录3。

- [官方发布通知](https://www.nhc.gov.cn/wjw/c100378/202402/afd5dda4bd6745fda10aad8d43a16369.shtml)

- 下载核对时间：2026-10-20；SHA-256及每道页码、原文保存在 `home-recipes.json`。
- 主料名称和用量已逐条与PDF文本核对；PDF页码比正文页码多2页。原文未逐道给油盐和完整步骤，这部分为本项目补充，不代表官方原配方。
- 全部一份菜；主料为生可食部重量，加工品按购买状态称重。鱼按去皮去骨鱼肉计，不按整条毛重；虾仁按解冻沥水后可食部计。用油全部计入配方，不假设残留率；水单列，不虚构成品熟重。
- 食材显示名用简体中文，`foodId`是TFDA原食品编号；地区名称对应、选定品种与调料见各项配料。盐明确采用有营养记录的岩盐，未用低钠盐替代；香干选五香豆干；瘦牛肉选修清前胸肉；鲈鱼选日本花鲈；青菜选小白菜。
- 大豆油、豆制品、鸡蛋、鱼、虾、小麦和芝麻等记录过敏原字段。包装加工品的实际配料仍以包装为准，DIY检索和生成会检查明确忌口，不能以此替代加工品包装核对。
- 营养按TFDA记录乘克数相加，保留缺失值，未做烹饪营养保留率修正；不将配方作为食药署直接测量的整菜，也不将官方全天营养总值复制给单道菜。
- 页面不增加来源或估算标签，追溯字段仅存于数据库。DIY和Agent食谱工具已接入自动检索；未命中才生成，通过食品编号、克数、厨具、时间及营养完整性校验后存入现有D1。相同条件再次使用不调用模型。
